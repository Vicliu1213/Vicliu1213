# Setup Guide

## Prerequisites

- Python 3.8+
- pip

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Vicliu1213/Vicliu1213.git
   cd Vicliu1213
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the setup script:
   ```bash
   bash scripts/setup.sh
   ```

## Running the Application

```bash
python src/main.py
```

## Running Tests

```bash
pytest tests/
```
